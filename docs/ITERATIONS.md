# 栖时：本次迭代记录

## 第一轮：建立完整闭环

- 建立 React + TypeScript + Electron 项目，以及 Windows 打包配置。
- 统一暖白、石墨灰和松绿视觉；原创矢量山景、桌面图标和深色主题。
- 接通任务、计时、休息、统计、设置、本地数据和桌面桥接。
- 让主进程持有计时状态，避免页面切换或迷你窗口导致计时重建。

## 第二轮：验证可靠性与真实桌面流程

- 增加对实际专注片段的记录，排除暂停和休眠，正确分配跨日时间。
- 增加备份结构校验、原子保存、自动回退和恢复前数据保留。
- 通过真实窗口验证添加任务、子任务、计时暂停／继续、完成、统计、删除撤销、重载和迷你模式。
- 修正表单控件的可访问名称；修正截图时捕获页面入场动画的问题。
- 迷你窗口计时结束时恢复主窗口，确保结果卡完整可见。
- 清除进入迷你窗口时残留的提示，避免遮挡开始按钮。

## 第三轮：人性化与边界检查

- 任务编辑增加未保存保护，未点击加号的子任务也随表单保存。
- 设置页离开前保护未保存修改；有修改时先保存再切换迷你模式。
- 增加月度专注日历，点击日期直接进入当日统计。
- 收紧低高度窗口的布局，保留主要计时操作的可见性。
- 验证托盘隐藏、模拟系统 suspend 事件、关闭进程再打开、迷你窗口自动结束和休息不计入统计。
- 修正弹窗快速打开时的键盘焦点竞态，弹窗开启期间将背景设为不可交互。
- 发行前再检查：数据写入失败保留常驻提示，原子替换失败仍保留上一份有效数据；验证关闭托盘选项后能干净退出；改善小字对比度、超长标题和正向计时显示。

## 交付范围

新增 Windows x64 一键安装发行方式：`Qishi-Setup-1.1.0-x64.exe`。当前用户安装，自动建立桌面与开始菜单快捷方式，安装后启动；提供 Windows 应用列表中的卸载入口，默认保留个人数据。`npm run package` 生成安装版，`npm run package:portable` 保留免安装版构建方式。

本次交付为 Windows x64 本地单人使用版本。应用无需账号；不包含跨设备云同步、团队协作或自动更新服务。源码和构建脚本一并保留，可继续扩展。
