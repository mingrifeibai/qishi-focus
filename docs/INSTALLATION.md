# 栖时 Windows 安装与分享

## 发给别人哪个文件？

发送 `release/Qishi-Setup-1.1.0-x64.exe` 即可。这是独立的 Windows x64 一键安装包，已经包含程序和运行环境，不需要发送项目源码、`node_modules`、其他 EXE 或整个 release 文件夹。

## 收到后怎么使用？

1. 将安装包保存到电脑，双击打开。
2. 安装程序自动安装到当前用户目录，显示安装进度，完成后启动栖时。
3. 之后双击桌面的「栖时」，或在开始菜单搜索「栖时」即可打开。

默认使用当前用户安装，不要求用户选目录或逐页点击向导。程序数据存放在独立的 Windows 用户数据目录，不跟随安装包的位置。安装完成后可以移走下载的安装包。

## 更新、重装与卸载

- 同一安装包可以重新安装；后续新版本应继续使用现有 appId，以维持同一安装和卸载身份。
- 安装版与免安装版使用相同应用身份和默认数据位置；已有任务与专注记录可以继续使用。安装前请退出正在运行的栖时。
- 在 Windows「设置 → 应用 → 栖时」选择卸载。卸载程序删除程序、桌面和开始菜单快捷方式，默认保留任务与专注记录。
- 数据路径可在程序「偏好设置」中查看。换电脑前导出 JSON 备份，在新电脑恢复。
- 当前没有联网自动更新服务，新版本通过新的安装包交付。

## 发行说明

本包是 Windows x64 版本，未制作 macOS、Linux、Windows ARM64 原生或 32 位安装包。当前未配置数字签名证书，Windows 可能显示未知发布者；如需公开正式发行，可在获得发布者证书后配置签名。文件校验值见 [SHA256SUMS.txt](SHA256SUMS.txt)，也随 Releases 附件提供。

安装器采用 electron-builder 的 NSIS 一键安装配置。相关选项与默认行为参考 [官方 NSIS 文档](https://www.electron.build/docs/nsis/)。本项目的实际安装验证结果保存在 `docs/installer-verification.json`。
