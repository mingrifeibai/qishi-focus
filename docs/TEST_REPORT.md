## 逻辑覆盖

1. 倒计时到期精确记录一次，任务不会自动误标完成。
2. 暂停不累计，继续后建立新的实际专注片段。
3. 休眠间隔与时间回退触发暂停，避免时长虚增。
4. 恢复备份／重新打开应用不计算离线时间。
5. 跨午夜专注分配到正确日期。
6. 休息不计入统计，长休息间隔生效。
7. 正向计时与提前结束记录正确。
8. 放弃和不足 1 秒的计时不生成记录。
9. 计时中禁止切换任务／模式，时长设置下一轮生效。
10. 删除任务保留历史，删除分类清理引用。
11. 拒绝损坏备份、重复 ID、无效日期和不一致的时间片段。
12. CSV 正确处理中文、引号、逗号和公式前缀。
13. 损坏数据回退到上一份有效自动备份，保留原文件。
14. 允许同名任务，拒绝重复分类名。
15. 已完成任务的选择与下一轮启动处理正确。
16. 原子替换失败仍保留上一份有效数据，恢复写入后能继续保存。
17. 1.0 备份自动补齐新增设置和任务字段，原数据保持不变。
18. 工作日跳过周末，完成重复任务不会因为恢复／再次完成而重复生成下一项。
19. 每日、每周重复跨年日期正确，错过多日时从当前日期继续安排。
20. 快捷输入正确识别空格分隔的日期、分类和优先级，保留普通文本。
21. 批量安排／完成原子执行并去重，无效输入不改变原状态。
22. 切换风格与环境音保留自选时长，不改变运行中的已用时间。
23. 复盘文字在备份与 CSV 中保留，并按原有导出规则安全转义。

## 桌面流程覆盖

- 创建带分类和子任务的任务 → 选择专注 → 开始 → 暂停 → 继续 → 提前结束 → 标记完成 → 查看统计 → 删除任务并撤销 → 迷你窗口 → 页面重载。
- 修改时长和主题、管理分类、原生文件对话框备份／恢复、无效备份拒绝、文字输入与快捷键互不干扰。
- 今日、任务、统计、设置、深色、960 × 680 小窗口、400 × 232 迷你窗口的截图；月历点击进入当日统计。
- 触发 Electron 的 suspend 事件 → 暂停 → 关闭应用进程 → 再次打开 → 恢复原进度 → 收进托盘 → 迷你窗口自动结束 → 展开结果卡 → 休息不增加专注统计。
- 未保存设置保护、任务搜索／收集箱、超长任务名、未点击加号的子任务保存、弹窗键盘焦点约束。
- 磁盘异常提示保持可见、恢复后清除提示、关闭托盘选项后正常退出并保存。
- 五套主题及深色模式切换、重载持久化、关闭动效、小窗口布局。
- 快速输入 → 批量安排今天 → 工作日重复 → 完成后生成下一项 → 写作模板 → Ctrl + K 搜索并选择任务；从有未保存修改的设置页选任务仍受到保护。
- 15 分钟预设、真实 Web Audio 音源启停、结束后的复盘保存和历史记录展示。声音测试验证调用生命周期，没有进行主观听感测评。

测试运行在 `.test-data/` 的隔离目录，不写入正式用户数据。桌面流程中备份文件选择与确认对话框由测试替代，实际读写和校验仍执行应用代码。
