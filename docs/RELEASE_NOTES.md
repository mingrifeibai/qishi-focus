## 下载哪个文件？

- **推荐：`Qishi-Setup-1.1.0-x64.exe`** — Windows 64 位一键安装版，自动创建桌面与开始菜单快捷方式。
- `Qishi-1.1.0.exe` — 免安装版，双击即可使用。
- `SHA256SUMS.txt` — 安装包与免安装版的 SHA-256 校验值。
- `INSTALL.txt` — 中文安装与分享说明。

分享给朋友只需发送安装包；无需源码、Node.js 或额外下载运行环境。页面下方的 Source code 是源代码，适合开发者。

## 主要功能

- 五套原创主题：松间留白、霓虹都市、积木工坊、烟雨江湖、像素牧场；支持深浅色。
- 任务与子任务、快捷输入、批量安排、重复任务、阅读／写作／学习模板。
- 番茄计时、深度专注、正向计时、暂停与休息、迷你置顶窗口。
- 专注统计、日历、复盘、环境音、像素伙伴成长。
- 本地离线保存、JSON 备份恢复、CSV 导出。

## 验证与说明

23 项逻辑测试、9 项真实桌面流程测试通过；安装包另行验证了安装、快捷方式、启动、重装和卸载。验证范围为本机 Windows x64，完整记录见仓库 docs/TEST_REPORT.md。

卸载默认保留个人任务与专注记录。当前发行包未配置数字签名，Windows 可能显示未知发布者；当前没有联网自动更新服务。
